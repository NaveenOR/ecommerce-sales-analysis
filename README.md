# E-Commerce Sales Analysis & Machine Learning

## Project Overview
An end-to-end data analytics and machine learning project analysing 100,000 e-commerce orders from 2020 to 2024.

The project explores sales performance, order failures, customer behaviour and predictive modelling using Python.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib
- SciPy
- Scikit-learn
- XGBoost
- JupyterLab

## Key Analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Statistical hypothesis testing
- Feature engineering
- Order failure classification
- Total order value regression
- Feature importance analysis
- Business recommendations

## Key Findings
- Total orders analysed: 100,000
- Total order value: 91.83 million
- Returned and cancelled orders: 6.08%
- Pending and shipped orders: 19.30%

## Machine Learning Results
Random Forest Regression:
- MAE: 17.50
- RMSE: 25.82
- R²: 0.9987

Note: The target, TotalAmount, is directly calculated from several input variables. Therefore, the high R² reflects accurate order-value estimation rather than independent future sales forecasting.
